# Provenance

This repository was extracted from the Mac-side remote connection paths in
`HD838A/remote-mic-app` while preserving their Git history.

The extracted implementation and tests were authored by Andy. No third-party
source code or additional GPL-licensed dependency was identified in the
extracted paths. The copyright holder is distributing this private repository
under the proprietary terms in `LICENSE`.

The package continues to use only Apple system frameworks (`Foundation`,
`Network`, `CryptoKit`, `SwiftUI`, and `CoreImage`) and has no external package
dependencies.
